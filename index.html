Auto-sync lewat Firebase. Member cukup buka link polos — tanpa tombol sync. Tiap admin menyimpan jadwal, data ikut ke cloud.

Cara buat Firebase (2 menit)
  1. Buka console.firebase.google.com → Create project
  2. Build → Realtime Database → Create Database → Start in test mode
  3. Copy URL (…firebasedatabase.app)
  4. Rules: pastikan .read dan .write true, Publish
  5. Di sini → Aktifkan sync → tempel URL
  6. Supaya semua device otomatis sync di link polos: isi variabel EMBEDDED_CLOUD_DB di kode dengan URL yang sama, lalu deploy ulang ke Vercel
